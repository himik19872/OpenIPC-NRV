# SKUD Controller (ESP32-P4)

Автономный контроллер системы контроля и управления доступом (СКУД) на базе
**ESP32-P4** (Waveshare ESP32-P4-WIFI6-DEV-KIT, модуль ESP32-P4-NR16).

Управляется **только по Ethernet** (без Wi-Fi): Wiegand-26 считыватель, реле
замка, геркон двери, кнопка выхода, зуммер. Встроенный веб-интерфейс и REST API
с HTTP Basic Auth, OTA-обновлением и хранением на littlefs (до 20 000 карт).

## Возможности

- **Wiegand 26** — до 2 считывателей (вход/выход) для модели «дверь с двумя
  считывателями».
- **Дверь** — 1 считыватель + кнопка выхода, либо 2 считывателя (вход/выход),
  антипасбек (antipassback) по направлению.
- **Карты** — facility + номер, ФИО владельца, тип доступа (постоянный / по
  расписанию), группа, активность. Ручной ввод, обучение с подключённого
  считывателя, импорт/экспорт JSON.
- **Расписания** — недельное (7 дней × время вкл/выкл) и «плавающее»
  (интервал дат).
- **Журнал событий** — кольцевой буфер 1000 записей (доступ к карте, отказ,
  открытие/закрытие двери по геркону, взлом и т.п.).
- **Сеть** — Ethernet, DHCP или статический IP; режим работы автономный/сетевой.
- **Время** — SNTP с настраиваемым сервером и периодом, ручная синхронизация,
  часовой пояс.
- **Syslog** — отправка событий на удалённый syslog-сервер (UDP).
- **OTA** — обновление прошивки `.bin` через веб-интерфейс.
- **Хранилище littlefs** — карты и журнал на разделе `storage` (7.8 МБ).

## Аппаратная часть

| Пин | Назначение | GPIO (по умолч.) |
|---|---|---|
| Wiegand D0/D1 (считыватель вход) | данные карты | 4 / 5 |
| Wiegand D0/D1 (считыватель выход) | данные карты | — (отключено) |
| Замок (реле) | выход открытия | 8 |
| Кнопка выхода (RTE) | вход | — |
| Геркон двери | вход | — |
| Зуммер | LEDC PWM | — |
| Ethernet RMII | IP101 PHY | EMAC по умолч. |

Пины настраиваются в веб-интерфейсе (вкладка «Пины») и применяются «на лету».
Полное описание см. в `main/board_config.h`.

## Сборка

Требуется **ESP-IDF v6.1**, таргет `esp32p4`.

```bash
idf.py set-target esp32p4
idf.py build
idf.py -p COM5 flash
```

> Чип ранней ревизии (v1.3): в `sdkconfig.defaults` включены
> `CONFIG_ESP32P4_SELECTS_REV_LESS_V3=y` и `CONFIG_ESP32P4_REV_MIN_100=y`,
> CPU 360 МГц.

### Управляемые компоненты (`main/idf_component.yml`)

- `espressif/cjson`
- `espressif/ip101` (Ethernet PHY)
- `joltwallet/littlefs` (файловая система)

## Таблица разделов

| Раздел | Назначение | Размер |
|---|---|---|
| `nvs` | настройки (config) | 64 КБ |
| `otadata` | OTA-состояние | 8 КБ |
| `ota_0` / `ota_1` | слоты прошивки | 3 МБ × 2 |
| `storage` | littlefs (карты + журнал) | ~7.8 МБ |
| `phy_init` | радио-калибровка | 4 КБ |

## REST API (краткий обзор)

Базовый адрес: `http://<IP контроллера>` (порт 80). Все запросы (кроме неявных)
требуют **HTTP Basic Auth** (заголовок `Authorization: Basic base64(login:password)`).

| Метод | Путь | Описание |
|---|---|---|
| GET | `/` | Веб-интерфейс (HTML) |
| GET | `/api/config` | Пины (lock/rte/sensor/wiegand/buzzer) |
| POST | `/api/config` | Сохранить пины |
| GET | `/api/sysconfig` | Системная конфигурация |
| POST | `/api/sysconfig` | Сохранить системную конфигурацию |
| GET | `/api/status` | Статус: uptime, heap, время, счётчики |
| GET | `/api/log` | Журнал событий (посл. 200) |
| POST | `/api/log/clear` | Очистить журнал |
| POST | `/api/door/open` | Открыть дверь |
| GET | `/api/cards` | Список карт |
| POST | `/api/cards/add` | Добавить карту |
| POST | `/api/cards/update` | Обновить карту |
| POST | `/api/cards/remove` | Удалить карту |
| POST | `/api/cards/clear` | Удалить все карты |
| GET | `/api/cards/export` | Экспорт карт (JSON) |
| POST | `/api/cards/import` | Импорт карт (JSON) |
| POST | `/api/cards/learn` | Включить режим обучения |
| GET | `/api/cards/learn` | Статус обучения |
| POST | `/api/cards/learn/cancel` | Отменить обучение |
| POST | `/api/time/sync` | Ручная синхронизация времени |
| POST | `/api/ota` | Загрузка прошивки (raw `.bin`) |
